Area Code Search

North American (+1) area codes — search by number, city, state or country.

Area codes show where a number was originally assigned, not necessarily where it is now. Data: Wikipedia "List of North American Numbering Plan area codes" (CC BY-SA 4.0); city and place names (~2013 snapshot; newer overlays inherit their base code's cities) and time zones from Google libphonenumber (Apache-2.0). Map outlines: UCLA Geoportal "North America Telephone Area Code Boundaries" (2015, public domain) via 1ec5/nanp-boundaries, plus Natural Earth (public domain) for 867; codes created since then reuse the outline of the codes they overlay. Base map: © OpenStreetMap contributors (needs a network connection; the outlines work without it).
